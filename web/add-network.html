Ручное добавление

Открой MetaMask → переключение сети → «Добавить сеть»
Выбери «Добавить сеть вручную»
Вставь параметры выше в поля
Сохрани → переключись на AIX OS
Твой AIX появится в списке активов
⚠️ MetaMask покажет нулевой баланс для 0x-адресов. Это нормально — наши AIX-адреса начинаются с AIX, а не с 0x. Полный функционал — в родном кошельке AIX OS.
