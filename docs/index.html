Как запустить

3 команды — и AIX OS работает локально

# Клонировать проект
git clone https://github.com/aix-os/aix-os.git
cd aix-os

# Установить зависимости
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# Запустить сеть (3 ноды)
.\scripts\run_all.ps1
1

Запусти ноды

Скрипт поднимет 2 ноды (порты 8010, 8011) и Web Wallet (9000).

2

Открой браузер

http://localhost:9000 — и увидишь Web Wallet со всеми фишками.

3

Попробуй фишки

Отправь AIX по @id, создай Gift-Link, заморозь капсулу времени, поучаствуй в PoC.
