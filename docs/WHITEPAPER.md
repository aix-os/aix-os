## Аннотация

AIX OS — это децентрализованная операционная система для повседневной
жизни, построенная на собственном блокчейне с нативным токеном AIX.

В отличие от существующих криптовалют (Bitcoin, Ethereum), AIX OS не
ограничивается ролью «цифровых денег» или «платформы смарт-контрактов».
Мы создаём среду, в которой технологии делают человека счастливее, а не
богаче.

**Ключевые отличия:**

- **AIX Brain** — локальная LLM встроена в ядро. Скажи «отправь 5 AIX маме» — система сделает.
- **12 уникальных протоколов** — подарки, капсулы времени, наследство,
  телефон → адрес, репутация, обмен и другие.
- **Мобильный кошелёк** на Flutter — Android и Windows, готов к запуску.
- **Настоящая приватность.** Приватный ключ физически не доступен AI.
  Отправка — только через подтверждение пользователя.
- **Дефляционная модель** с реинвестированием в развитие проекта
  (Treasury DAO).

## 1. Проблема

### 1.1. Современная криптовалюта — для гиков, а не для людей

За 15 лет существования Bitcoin и Ethereum мы получили:

- Миллиарды долларов капитализации
- Десятки тысяч проектов
- Но **менее 5% населения мира** когда-либо пользовались криптой

Причины:

- **Сложность.** 12 seed-слов, приватные ключи, газ, slippage, MEV.
- **Безликость.** Адрес `0x8f3c...9a2b` — не человек. Нет имён, нет лиц.
- **Отсутствие пользы.** Кроме спекуляций и DeFi-игр — реальных сценариев мало.
- **Потерянные монеты.** ~4 млн BTC потеряно навсегда из-за смерти владельцев.
- **Отсутствие AI.** ChatGPT отдельно, кошелёк отдельно, банк отдельно.

### 1.2. Что мы хотим изменить

Мы строим AIX OS — систему, где:

1. **Отправить деньги маме** — так же просто, как написать сообщение.
2. **Твои монеты не потеряются**, если с тобой что-то случится.
3. **AI помогает** — не как внешний чат-бот, а как встроенный напарник.
4. **Вклад в проект вознаграждается** — не только майнинг, но и код,
   переводы, дизайн.

## 2. Решение: AIX OS

### 2.1. Что такое AIX OS

**AIX OS** — это:

- **Свой блокчейн** (Proof of Work, ECDSA secp256k1, SHA-256).
- **AIX Brain** — локальная LLM с 19 инструментами управления системой.
- **12 уникальных протоколов** (см. раздел 3).
- **P2P-сеть** нод с автоматической синхронизацией.
- **Мобильный кошелёк** (Flutter — Android + Windows).
- **Web Wallet** — браузерный интерфейс.
- **CLI + REST API** — для разработчиков.

### 2.2. Почему это работает

В отличие от Bitcoin (только деньги) и Ethereum (только смарт-контракты),
AIX OS — **полный стек**:

| Слой | Что даёт |
|------|----------|
| Блокчейн | Надёжность, децентрализация |
| P2P-сеть | Синхронизация между нодами |
| AIX Brain | Голосовое и текстовое управление |
| 12 протоколов | Уникальные фишки |
| AIX-ID | Паспорт творца |
| Мобильный кошелёк | Массовое принятие |
| Web Wallet | Простой вход |

## 3. Уникальные протоколы (killer-фичи)

### 3.1. AIX Brain — AI-напарник (#AI-1)

**Локальная LLM (Ollama), встроенная в ядро ОС.** Понимает 19 инструментов:

- **Чтение:** состояние ноды, баланс, DAO, PoC, подарки, капсулы, пулы.
- **Память:** записывает и читает AI Memory — долгосрочная память AI.
- **Действия:** отправка AIX, создание подарков и капсул, обмен,
  выдача медалей, регистрация AIX-ID.

**Безопасность:**
- LLM **никогда** не видит приватный ключ.
- Отправка транзакции — только через CLI с явным подтверждением `y/N`.
- Через HTTP API отправка отключена (`NullSigner`).
- Тест `test_no_private_key_leak_in_any_result` доказывает, что ключ не
  появляется ни в одном результате инструмента.

**Как это выглядит:**
вы> отправь 1 AIX bob
🧠 Brain думает...
┌─── ПОДТВЕРЖДЕНИЕ ОТПРАВКИ ──────────────────
│ От: alice
│ Кому: @bob
│ Сумма: 1.0 AIX
│ Баланс: 200.0 → 199.0 AIX
└─────────────────────────────────────────────
Отправить? [y/N] y
✅ Отправлено. TX: dec9b1b3...

### 3.2. AI Memory (#AI-2)

Память AI на блокчейне. Каждое важное событие — структурированное
воспоминание с типом, приоритетом и тегами. AI-напарник помнит все
решения и открытия проекта, даже после сброса контекста.

### 3.3. AIX Contacts — отправка по телефону

Привязка номера телефона к AIX-адресу через SHA-256 хеш.
**Никто не хранит номера** — только хеши. Приватность by design.

### 3.4. Dead Man's Switch — наследство

Если владелец не выходил на связь 12 месяцев, его AIX автоматически
распределяются между наследниками. **У Bitcoin такого нет.**

### 3.5. Proof of Contribution — награды за вклад

Фонд, пополняемый сообществом. Вклад в код, перевод, дизайн — всё
вознаграждается через DAO-подтверждение.

### 3.6. AIX-ID — паспорт творца

Публичное имя `@alice` вместо `0x8f3c...9a2b`. Репутация, медали, история.

### 3.7. TimeLock Wallets — капсулы времени

Заморозить AIX до 2027 года? Легко. Подарить сыну на 18-летие? Да.

### 3.8. SBT — медали чести

Непередаваемые токены. Нельзя продать. Только заслужить.

### 3.9. AIX Lottery — лотерея честности

1 из 1000 блоков даёт случайному адресу 100 AIX. Детерминированно,
проверяемо, неподкручиваемо.

### 3.10. Burn-to-Mint — сожги и создай

Сжигаешь AIX — получаешь уникальный артефакт. Дефляция + коллекция.

### 3.11. Gift-Link — подарки по ссылке

Отправь AIX человеку без кошелька. Пусть активирует — получит.

### 3.12. Swap — внутренний AMM

Обмен **20 токенов** через пулы ликвидности. Формула `x*y=k`, как Uniswap
V2. Комиссия 0.3%: 0.1% идёт основателю (founder), 0.2% — LP-держателям.

**Список токенов:** AIX, USDT, USDC, BTC, ETH, BNB, SOL, TON, XRP, ADA,
DOGE, DOT, MATIC, AVAX, LTC, TRX, LINK, ATOM, UNI, XMR.

### 3.13. Faucet — кранец для новых

Первые 10 AIX бесплатно. Один адрес — один раз. Один IP — раз в 24 часа.

## 5. Технология

### 5.1. Блокчейн

- **Консенсус:** Proof of Work (SHA-256, двойной хеш).
- **Криптография:** ECDSA secp256k1 (как Bitcoin).
- **Адреса:** Base58Check с префиксом `AIX`.
- **Автоподстройка сложности:** каждые 10 блоков.
- **Защита от опустошения пулов:** резерв не может упасть ниже 5%.

### 5.2. P2P-сеть

- Ноды общаются по HTTP (простота на старте).
- State Sync: gift, timelock, SBT, AIX-ID, DMS, Burn, Contacts, Swap,
  PoC, DAO.
- Разрешение конфликтов: longest chain with most work.

### 5.3. AIX Brain

- **LLM:** Ollama, локальная. По умолчанию `qwen2.5:3b` — работает
  на 8 GB RAM.
- **Стек:** Python + FastAPI + Ollama API.
- **19 инструментов** через tool-calling.
- **Безопасность:** отдельный слой signer — LLM не имеет доступа к ключам.

### 5.4. Мобильный кошелёк

- **Flutter** — один код на Android и Windows.
- **Криптография:** сходится с Python-частью (проверено тестом).
- **Хранение ключей:** `flutter_secure_storage` (Keystore, Keychain, DPAPI).
- **Функции:** майнинг, история, обмен, медали, PoC, контакты, отправка
  с локальной подписью.

### 5.5. Web Wallet

- Чистый HTML + JS + Chart.js.
- Все 12 протоколов + Brain в браузере.
