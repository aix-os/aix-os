## Аннотация

AIX OS — это децентрализованная операционная система для повседневной жизни,
построенная на собственном блокчейне с нативным токеном AIX. В отличие от
существующих криптовалют (Bitcoin, Ethereum), AIX OS не ограничивается ролью
«цифровых денег» или «платформы смарт-контрактов». Мы создаём среду, в которой
технологии делают человека счастливее, а не богаче.

**Ключевые отличия:**
- ИИ встроен в ядро, а не является надстройкой
- 12 уникальных протоколов, которых нет ни у одного блокчейна
- Отправка денег по номеру телефона (AIX Contacts)
- Наследство на блокчейне (Dead Man's Switch)
- Награды за реальный вклад (Proof of Contribution)
- Web Wallet и мобильное приложение в одном протоколе

## 1. Проблема

### 1.1. Современная криптовалюта — для гиков, а не для людей

За 15 лет существования Bitcoin и Ethereum мы получили:
- Миллиарды долларов капитализации
- Десятки тысяч проектов
- Но **менее 5% населения мира** когда-либо пользовались криптой

Причины:
- **Сложность.** 12 seed-слов, приватные ключи, газ, slippage, MEV.
- **Безликость.** Адрес `0x8f3c...9a2b` — не человек. Нет имён, нет лиц.
- **Отсутствие пользы.** Кроме спекуляций и DeFi-игр — реальных сценариев мало.
- **Потерянные монеты.** ~4 млн BTC потеряно навсегда из-за смерти владельцев.

### 1.2. Что мы хотим изменить

Мы строим AIX OS — систему, где:
1. **Отправить деньги маме** — так же просто, как SMS.
2. **Твои монеты не потеряются**, если с тобой что-то случится.
3. **ИИ помогает** — не как чат-бот, а как встроенный советник.
4. **Вклад в проект вознаграждается** — не только майнинг, но и код, переводы, дизайн.

## 2. Решение: AIX OS

### 2.1. Что такое AIX OS

**AIX OS** — это:
- **Свой блокчейн** (Proof of Work, ECDSA secp256k1, SHA-256).
- **12 уникальных протоколов** (см. раздел 3).
- **P2P-сеть** нод с автоматической синхронизацией.
- **Web Wallet** — браузерный интерфейс.
- **CLI + REST API** — для разработчиков.
- **Мобильное приложение** — в разработке.

## 3. Уникальные протоколы (killer-фичи)

### 3.1. AIX Contacts — отправка по телефону
Привязка номера телефона к AIX-адресу через SHA-256 хеш.
**Никто не хранит номера** — только хеши. Приватность by design.

### 3.2. Dead Man's Switch — наследство
Если владелец не выходил на связь 12 месяцев, его AIX
автоматически распределяются между наследниками. **У Bitcoin такого нет.**

### 3.3. Proof of Contribution — награды за вклад
Фонд, пополняемый сообществом. Вклад в код, перевод, дизайн —
всё вознаграждается через DAO-подтверждение. Как Gitcoin, но в протоколе.

### 3.4. AIX-ID — паспорт творца
Публичное имя `@alice` вместо `0x8f3c...9a2b`. Репутация, медали, история.

### 3.5. Time-Lock Wallets — капсулы времени
Заморозить AIX до 2027 года? Легко. Подарить сыну на 18-летие? Да.

### 3.6. SBT — медали чести
Непередаваемые токены. Нельзя продать. Только заслужить.

### 3.7. AIX Lottery — лотерея честности
1 из 1000 блоков даёт случайному адресу 100 AIX. Детерминированно,
проверяемо, неподкручиваемо.

### 3.8. Burn-to-Mint — сожги и создай
Сжигаешь AIX — получаешь уникальный артефакт. Дефляция + коллекция.

### 3.9. Gift-Link — подарки по ссылке
Отправь AIX человеку без кошелька. Пусть активирует — получит.

### 3.10. Swap — внутренний AMM
Обмен AIX-SIM ↔ USDT-SIM ↔ BTC-SIM. Формула `x*y=k`, как Uniswap.

### 3.11. P2P + State Sync
Ноды синхронизируются автоматически. Все фишки работают между ними.

### 3.12. Веб-кошелёк
Всё в браузере. Никаких расширений. Никаких seed-фраз.

## 4. Токеномика

| Параметр | Значение |
|----------|----------|
| Тикер | **AIX** |
| Максимальная эмиссия | 21 000 000 AIX |
| Decimals | 18 |
| Награда за блок | 50 AIX |
| Халвинг | каждые 210 000 блоков |
| Комиссия | 0.01% (0% при репутации 900+) |
| Pre-mine | 0% (честный запуск) |
| Консенсус | PoW → PoS → DAG |

**Распределение:**
- 90% — майнинг (постепенно, через PoW)
- 10% — фонд развития (PoC, гранты, маркетинг)

**Дефляция:**
- 1% каждой транзакции → в фонд AIX Kindness
- Burn-to-Mint — прямые сжигания AIX за артефакты

## 5. Технология

### 5.1. Блокчейн

- **Консенсус:** Proof of Work (SHA-256, двойной хеш)
- **Криптография:** ECDSA secp256k1 (как Bitcoin)
- **Адреса:** Base58Check с префиксом `AIX`
- **Merkle-tree:** для транзакций в блоке
- **Автоподстройка сложности:** каждые 10 блоков

### 5.2. P2P-сеть

- Ноды общаются по HTTP (для простоты) — на старте
- Позже — P2P-сокеты + Kademlia DHT
- State Sync: gift, timelock, SBT, AIX-ID, DMS, Burn, Contacts, Swap, PoC
- Разрешение конфликтов: longest chain with most work

### 5.3. Web Wallet

- Чистый HTML + JS + Chart.js (без React/Vue — простота)
- CORS-ready API
- Все 12 фишек в браузере

### 5.4. Мобильное приложение

- Flutter (в разработке)
- QR-сканер, контакты, отправка по телефону
