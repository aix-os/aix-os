# AIX OS: как я построил операционную систему, которая слышит тебя

> **TL;DR.** Я сделал блокчейн с локальным AI-напарником.
> Ты пишешь «отправь 5 AIX маме» — система делает.
> Приватный ключ LLM не видит никогда. 52 теста. Код открыт.
> Это не про крипту. Это про ОС, в которой не надо учить кнопки.

---

## С чего всё началось

Я устал от крипты.

Не от технологии — от **UX**. Каждый кошелёк, каждая биржа, каждый DeFi-протокол требуют, чтобы ты выучил их интерфейс. Нажимал их кнопки. Понимал их терминологию.

А потом я подумал: **а что если ОС можно просто попросить?**

> «Отправь 5 AIX напарнику bob»

И всё. Без формы. Без QR-кода. Без подтверждения в 4 экрана.

Так родилась AIX OS — децентрализованная операционная система для жизни.

## Что уже работает (не концепт, не roadmap — вот оно)

### 1. Собственный блокчейн

- PoW, ECDSA secp256k1, адреса `AIX…` через Base58Check.
- Максимум 21 000 000 AIX. Pre-mine: **0%**.
- Награда 50 AIX, халвинг каждые 210 000 блоков.
- Два узла синхронизируются, State-Sync через события.

### 2. Двенадцать протоколов — не DeFi-игрушки

Каждый решает реальную задачу человека:

| Протокол | Что делает |
|---|---|
| 🎁 Gift | Подарочные ссылки — отправил, друг активировал |
| 🕰️ TimeLock | Капсулы времени — открой через год |
| 🏅 SBT | Soulbound-медали, репутация без продажи |
| 🎰 Lottery | Встроенный розыгрыш каждые N блоков |
| 🎗️ DMS | Dead Man's Switch — наследство работает |
| 🪪 AIX-ID | `@alice` вместо `AIXTA5WAv...` |
| 🔥 Burn-to-Mint | Сжигаешь AIX — получаешь артефакт |
| 📇 Contacts | Телефон → адрес, с хешем и приватностью |
| 💱 Swap-AMM | x*y=k, обмен токенов |
| 🧬 PoC | Proof of Contribution — награды за вклад |
| 🔄 State-Sync | Синхронизация состояния между нодами |
| 🧠 AI Memory | Память AI прямо на блокчейне |

### 3. AIX Brain — то, ради чего всё это

**Локальная LLM (Ollama), встроенная в ОС.**

Ты пишешь в терминале:

```
$ python cli/main.py brain chat --wallet alice

🧠 AIX Brain — interactive mode (qwen2.5:3b)

you> отправь 1 AIX bob
🧠 Brain thinks...
┌─── SEND CONFIRMATION ────────────────────────────────
│ От:     alice
│ Кому:   @bob
│ Сумма:  1.0 AIX
│ Баланс: 200.0 → 199.0 AIX
└──────────────────────────────────────────────────────
Send? [y/N] y
✅ Sent. TX: dec9b1b3…  Broadcast to 1 peer.
```

**Что произошло:**
1. Ты сказал на естественном языке.
2. LLM распознала интент и вызвала tool `safe_send`.
3. Tool построил preview — **до того как коснуться ключа**.
4. Ты подтвердил `y/N`.
5. Только теперь ключ прочитался с диска, транзакция подписалась, ушла в сеть.

Ни на одном шаге **LLM не увидела приватный ключ**. Ни в промпте, ни в tool'ах, ни в логах.

### 4. Web Wallet с Brain прямо в браузере

Открываешь `http://localhost:9000` → вкладка 🧠 Brain → пишешь «Какая высота цепочки?» → через 10 секунд ответ.

**Но:** через браузер отправить деньги **физически невозможно**. HTTP API работает с `NullSigner` — заглушкой, которая никогда не подписывает.

## Как это работает под капотом

### Слои

```
ai/brain/
├── config.py         — конфиг из env (модель, URL, таймаут)
├── client.py         — HTTP-клиент к Ollama (только транспорт)
├── tools.py          — 8 инструментов + JSON-схемы для tool-calling
├── memory_bridge.py  — мост в AI Memory (in-process, не по сети)
├── signer.py         — BaseSigner / NullSigner / CLISigner
└── agent.py          — оркестратор: LLM ↔ tools ↔ ответ
```

### Цикл агента

```
user_msg
  │
  ▼
LLM (с tools) ──── есть tool_calls? ──── нет ──▶ финальный текст
  │                     │
  │                     да
  │                     ▼
  │              выполнить tools
  │                     │
  │              вернуть результаты LLM
  │                     │
  └─────────◀───────────┘
```

Предел итераций — 5. Защита от зацикливания.

### Почему это безопасно

| Угроза | Защита |
|---|---|
| LLM сольёт приватный ключ | Ключ живёт за `CLISigner`. LLM его не видит. |
| Prompt-injection заставит отправить | У LLM **нет** signer'а. Она не может. |
| Атакующий дёрнет `/brain/ask` | HTTP-агенты получают `NullSigner`. Отправка невозможна. |
| Кривой AIX-ID резолвится в мусор | Адрес валидируется: `AIX` + длина ≥ 30. |
| Случайная отправка при «сколько стоит?» | Есть отдельный `preview_send` без сайд-эффектов. |

Тест `test_no_private_key_leak_in_any_result` проверяет, что слово `private_key` не появляется ни в одном результате инструмента. 52 теста проходят.

## Что реально круто (честно)

**1. Мы первые в категории «ОС + AI + блокчейн».**
Есть LLM-кошельки. Есть блокчейны с AI. Но **операционная система для жизни, которая говорит с тобой** — это новая категория. Мы в ней первые.

**2. Приватность как аксиома, а не как фича.**
Ни один LLM в мире — ни OpenAI, ни Anthropic, ни локальный — не может слить твои деньги. Ключ физически вне его досягаемости. Это доказывается тестом, а не словами.

**3. Работает на 8 GB RAM.**
`qwen2.5:3b` — 1.9 GB. Умная, влезает, отвечает по-русски. Не надо GPU, не надо 32 GB.

**4. Всё локально.**
Никаких серверов, телеметрии, облачных баз. Твой кошелёк, твои ключи, твоя машина.

## Попробуй сам за 3 минуты

```bash
git clone https://github.com/aix-os/aix-os.git
cd AIX-OS
python -m venv .venv
.venv\Scripts\Activate.ps1        # Windows
# source .venv/bin/activate        # Linux/Mac
pip install -r requirements.txt

# Ollama: https://ollama.com/download
ollama pull qwen2.5:3b

.\scripts\run_all.ps1
python cli/main.py brain chat --wallet alice
```
